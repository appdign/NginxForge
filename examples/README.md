# 별도 참고 자료

이 디렉터리는 운영 conf에 복사하지 않습니다. 운영 설정은 conf의 nginx.conf,
policy.conf, site.conf, mime.types 네 파일이며 사이트별 조정은 site.conf에서만 합니다.

legacy-r8은 이전 릴리즈의 분할 정책/샘플을 보관한 기록입니다. 현재 설정과 함께
활성화하지 않습니다. 새 사이트 생성용 원본은 config/site-template.conf입니다.
프론트/Spring Boot 코드 점검 프롬프트와 backend 업로드 YAML은 docs/prompts,
docs/backend에서 별도로 제공합니다. 운영 패키지에는 포함하지 않습니다.
